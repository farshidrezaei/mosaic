# نرمال‌سازی چرخش ویدیو (Orientation Normalization)

ویدیوهای ضبط‌شده با گوشی‌های هوشمند اغلب دارای متادیتای چرخش ۹۰، ۱۸۰ یا ۲۷۰ درجه هستند. 

کتابخانه Mosaic از دو روش برای مدیریت چرخش استفاده می‌کند:

## ۱. نرمال‌سازی خودکار در خط‌لوله (توصیه‌شده)

```go
mosaic.EncodeHls(ctx, job, mosaic.WithNormalizeOrientation())
```
در این حالت:
1. متادیتای ماتریس چرخش بازرسی می‌شود.
2. فریم‌های ویدیو به صورت فیزیکی چرخانده می‌شوند.
3. تگ‌های چرخش در فایل خروجی پاک می‌شوند تا پلیرها دچار خطای چرخش مضاعف نشوند.
4. فایل‌های میانی پس از اتمام پکیجینگ به طور خودکار پاک می‌شوند.

## ۲. تابع نرمال‌سازی مستقل (Standalone)

```go
err := mosaic.NormalizeVideoOrientation(ctx, "mobile_video.mp4", "normalized_video.mp4")
```
